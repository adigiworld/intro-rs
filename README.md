# Rust Introductory Projects

A collection of **small and beginner-friendly Rust projects** created while learning the fundamentals of the Rust programming language.

The goal of this repository is to learn Rust by building simple programs and gradually exploring its core concepts.

## 📚 What You'll Learn

These projects cover introductory Rust concepts such as:

* Variables and mutability
* Data types
* Functions
* Control flow
* Loops
* Ownership and borrowing
* References
* Structs and enums
* Pattern matching
* Collections
* Error handling
* Modules
* Basic file handling
* Command-line input
* Working with `Cargo`

## 📂 Project Structure

Each project is kept small and focused on a particular Rust concept.

```text
rust-intro-projects/
├── hello/
├── gcd/
├── project-03/
├── project-04/
├── ...
└── README.md
```

The projects are intentionally simple so that each one can be understood independently.

## 🛠️ Requirements

To run these projects, you'll need:

* [Rust](https://www.rust-lang.org/)
* Cargo (included with Rust)

You can check your installation with:

```bash
rustc --version
cargo --version
```

## 🚀 Running a Project

Clone the repository:

```bash
git clone https://github.com/adigiworld/intro-rs.git
cd intro-rs
```

Navigate to a project:

```bash
cd hello
```

Run it with Cargo:

```bash
cargo run
```

For projects that are simple standalone Rust files, you can also use:

```bash
rustc main.rs
./main
```

## Purpose

This repository is primarily a **learning playground** rather than a collection of production-ready applications.

Each project is designed to answer questions like:

> "How does this Rust feature work?"

By keeping the projects small, it becomes easier to experiment, modify the code, and understand Rust's behavior.

## Learning Progress

The projects are roughly organized from simpler concepts to more advanced introductory concepts.

```text
Basics
  ↓
Variables & Data Types
  ↓
Functions & Control Flow
  ↓
Ownership & Borrowing
  ↓
Structs & Enums
  ↓
Collections
  ↓
Error Handling
  ↓
Small Practical Projects
```
